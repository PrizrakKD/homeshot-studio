Вход

Нужен GitHub-токен с доступом к репозиторию homeshot-studio. Создайте его здесь: Repository access → Only select repositories → homeshot-studio; Permissions → Contents: Read and write. Токен хранится только в этом браузере.

Черновики с Авито

Сюда попадают фото из расширения. Выберите лучший вариант и нажмите «В форму», чтобы кадрировать и опубликовать.
