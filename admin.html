Вход

Нужен GitHub-токен с доступом к репозиторию homeshot-studio. Создайте его здесь: Repository access → Only select repositories → homeshot-studio; Permissions → Contents: Read and write. Токен хранится только в этом браузере.

Черновики с Авито

Сюда попадают фото из расширения. Отметьте пары галочками, выберите вариант «после», при необходимости кадрируйте и нажмите «Опубликовать».

Ручная загрузка

Для фото с компьютера или телефона. Фото сжимаются автоматически. На сайте работа появится через 1–2 минуты после публикации.

MP4 до 50 МБ

Двигайте рамку и колёсиком или щипком меняйте масштаб. Для ползунка на сайте лучше, чтобы оба фото были 1:1 и с похожим кадром: тогда «до» и «после» совпадают при сравнении.
