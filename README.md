# Homeshot Studio

Сайт-портфолио: фото и видео для объявлений о квартирах.

## Как добавить работу

1. Откройте папку `works` в репозитории на GitHub.
2. Нажмите **Add file → Upload files** и перетащите папку с работой (например `2026-10-29-pugacheva`).
3. Внутри папки:
   - `before.jpg`: фото до (можно вертикальное)
   - `after.jpg`: фото после (квадрат)
   - `video.mp4`: видео, необязательно (лучше до 20 МБ)
   - `info.txt`: необязательно; первая строка: название, вторая: подпись
4. Нажмите **Commit changes**. Через 1–2 минуты работа появится на сайте.

Фото сжимаются автоматически, загружайте в любом размере (JPG, PNG, WEBP).
Новые работы показываются первыми: начинайте имя папки с даты.
Первая работа автоматически встаёт в шапку сайта.

## Как удалить работу

Откройте папку работы, у каждого файла нажмите **⋯ → Delete file** и сохраните.
