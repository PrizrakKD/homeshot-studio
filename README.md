# Homeshot Studio

Сайт-портфолио: фото и видео для объявлений о квартирах.

## Админка

Откройте `https://prizrakkd.github.io/homeshot-studio/admin.html`.
Там можно добавлять и удалять работы и менять контакты без захода на GitHub.
Для входа нужен GitHub-токен: Settings → Developer settings → Fine-grained tokens,
доступ только к репозиторию homeshot-studio, Permissions → Contents: Read and write.

## Фото с Авито: расширение + авто-генерация

### 1. Установить расширение (один раз)
1. Скачайте репозиторий (Code → Download ZIP) и распакуйте. Нужна папка `extension`.
2. В Chrome откройте `chrome://extensions`, включите **Режим разработчика**.
3. **Загрузить распакованное расширение** → выберите папку `extension`.
4. Нажмите на значок Homeshot в панели браузера → вставьте GitHub-токен → **Сохранить и проверить**.

Теперь на странице любого объявления Авито справа внизу есть кнопка **«В Homeshot»**:
отметьте нужные фото и нажмите «Отправить». Фото попадают в папку `drafts`.

### 2. Генерация

**Вариант А (по подписке Higgsfield, без API):** напишите Claude «обработай черновики Homeshot».
Claude сгенерирует варианты через вашу подписку и положит ссылки в `drafts/<id>/remote.json`,
а GitHub сам скачает картинки в черновик. Пока черновик ждёт, в админке он помечен «Ждёт обработки».

**Вариант Б (автоматически, через API Higgsfield, тариф API отдельный):**
Settings → Secrets and variables → Actions:
- вкладка **Secrets**: `HF_KEY_ID` и `HF_KEY_SECRET` (ключ из console.higgsfield.ai);
- вкладка **Variables**: `HF_MODEL_PATH`: путь модели из консоли Higgsfield (страница модели → API), без `https://api.higgsfield.ai/`.

Необязательные переменные:
- `HF_BODY`: тело запроса в JSON, если у модели другие поля. Подстановки: `{{prompt}}`, `{{image_url}}`, `{{num_images}}`.
  По умолчанию: `{"prompt":"{{prompt}}","input_images":[{"type":"image_url","image_url":"{{image_url}}"}],"aspect_ratio":"1:1","num_images":"{{num_images}}"}`
- `HF_PROMPT`: свой промпт.
- `HF_VARIANTS`: сколько вариантов на фото (1–4, по умолчанию 2).

### 3. Утвердить в админке
Вкладка «Черновики с Авито»: выберите лучший вариант → **В форму** → кадрирование → **Опубликовать**.
«Ещё варианты» перегенерирует одно фото, «Перегенерировать всё» весь черновик. Если генерация упала, текст ошибки виден в карточке черновика.

## Как добавить работу вручную

1. Откройте папку `works` в репозитории на GitHub.
2. Нажмите **Add file → Upload files** и перетащите папку с работой (например `2026-10-29-pugacheva`).
3. Внутри папки:
   - `before.jpg` и `after.jpg`: одна пара до/после;
     для нескольких пар в одном объекте: `01-before.jpg`, `01-after.jpg`, `02-before.jpg`, `02-after.jpg` и т.д.
     (на сайте у объекта появятся стрелки ‹ ›)
   - `video.mp4`: видео, необязательно (лучше до 20 МБ)
   - `info.txt`: необязательно; первая строка: название, вторая: подпись
4. Нажмите **Commit changes**. Через 1–2 минуты работа появится на сайте.

Фото сжимаются автоматически, загружайте в любом размере (JPG, PNG, WEBP).
Новые работы показываются первыми: начинайте имя папки с даты.
Первая работа автоматически встаёт в шапку сайта.

## Как удалить работу

Откройте папку работы, у каждого файла нажмите **⋯ → Delete file** и сохраните.
