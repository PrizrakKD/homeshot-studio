# Обработка черновиков (инструкция для Claude)

Очередь: в `drafts/<id>/` лежит `request.json` (кнопка «Сделать красиво») или `regen.json`
(«Ещё варианты» / «Перегенерировать всё»; `items` пустой = все фото, иначе ключи фото, например `["02"]`).

Для каждого такого черновика:
1. Посмотреть каждое фото `src/NN.jpg` и определить тип комнаты.
2. Импортировать фото в Higgsfield по ссылке
   `https://raw.githubusercontent.com/PrizrakKD/homeshot-studio/main/drafts/<id>/src/NN.jpg` (media_import_url).
3. Сгенерировать 2 варианта: модель `nano_banana_2_1`, `resolution: 2k`, `aspect_ratio: 1:1`.
   Промпт под тип комнаты: сохранить планировку, стены, окна, двери, встроенную мебель и технику на своих местах;
   широкий угол, ровные вертикали, тёплый вечерний свет; убрать беспорядок и логотип Авито.
   Для ванной и туалета не упоминать кровати и людей: фильтр Higgsfield может ошибочно сработать.
   Если вариант отклонён (nsfw), переформулировать нейтральнее и повторить один раз.
4. Записать ссылки на результаты в `drafts/<id>/remote.json`:
   `{"variants": {"01": ["url1", "url2"], "02": [...]}}`
   (только обработанные фото; для regen с `items` только перечисленные).
5. Закоммитить и запушить. GitHub Action «Обработать черновики» скачает картинки в `gen/`,
   удалит `remote.json`, `request.json`, `regen.json` и пометит черновик «Готово».
